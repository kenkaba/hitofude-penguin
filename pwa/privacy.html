プライバシーポリシー

ひとふでペンギン（iOS / Android アプリ・Web版）　制定日：2026年9月27日

集める情報

このアプリは、個人を特定できる情報を集めません。アカウント登録、広告、アクセス解析、位置情報の利用はありません。

端末に保存する情報

クリアしたステージ、★の数、きせかえ、サウンド設定だけを、お使いの端末の中に保存します。この情報が開発者や第三者へ送られることはありません。アプリを削除すると消えます。

外部との通信

アプリ版はゲームの動作に通信を使いません。Web版は表示用のフォント（Google Fonts）を読み込むことがあります。

お子さまの利用

年齢を問わず安心して遊べるよう、お子さまの情報も含めて一切収集しません。

GitHub の Issues からご連絡ください。
