# World artwork generation

Created with the built-in image_gen.imagegen tool, one independent generation for each of the 16 new worlds. Existing cyber-city.webp is World 01. No recolor variants, external artwork, external fonts, or procedural placeholder substitutions were used. Source outputs were RGB PNG; delivery assets were resized to 768 × 1152 and encoded WebP quality 85, method 6 with Pillow. This is format/size optimization only. Runtime integration belongs to the main application.
