# 素材を使うパズルの改修

背景に加えて支持台の外観・物理特性を変更。氷の滑走、反発板からの折り返し、搬送後の折り返しを専用配置にした。遠隔の短い重りを追加する生成処理を撤廃。既存の線スイッチは8・41面に残す。

全50面×6条件300/300成功。全50面で無描画クリア不可。代表4・10・13面は、同じ著者線で素材を通常床に戻すと失敗する。物理回帰13、棒の安定性3、素材7、設計復元とリレー6、レベル4、UI9のチェック成功。

線の compound 慣性修正を保持。反発は新規接触時だけ作用し、30秒置いた棒へ継続してエネルギーを足さない。

50面には左右反転・重力差・リレー応用を含む系列があり、50種類の完全に独立した発想ではない。端末Safariの実機試験は含まない。
