# LUMA FLOW — NEON CIRCUIT

スマートフォン向け、描いた線が落下する50ステージの物理パズル。

公開URL: https://kenkaba.github.io/hitofude-penguin/luma-flow/

## 遊び方

1. 指で線を描いて離すと、線が重力で落下します。
2. 足場と重心を考えて導水路を組み、注水します。
3. 丸いリレーへ水を通すと、配線でつながった隔壁が開きます。
4. すべての貯水セルを目標まで満たせばクリアです。

注水後は「設計に戻る」で線を残して修正できます。「一筆戻す」で最後の線を戻して描き直せます。通常/2倍速を切り替えられます。ヒントは段階式、お手本のクリアは記録されません。iPhoneはSafariの共有→ホーム画面に追加で起動できます。

## Cyber edition の変更

- 50ステージを維持し、序盤9面を9種類の構造に変更。
- 26面・39個の水起動リレーを導入。2セル面には交差回路を採用。
- 注水前の設計状態を復元する再試行、固定物理刻みでの2倍速。
- 不足水量・排水損失・未作動リレーを失敗時に表示。
- 都市・金属設備・ガラスセル・連続した発光水流のサイバーパンク表現。
- 再構成されたステージの進行はv3として別保存。旧v2記録は削除しません。

## 開発

Node.js 20以上。サーバー/API/外部CDNへの依存なし。

```sh
npm run dev
npm run build
npm test
```

`dist/`が配信物。`scripts/create-levels.cjs`から50面を生成します。回路センサーは著者解の水経路をサンプリングして配置されます。`tests/campaign.cjs`は50面×6条件を検証します。

`node tests/ui.cjs`は実際の描画コードとDOMモックのUI検証です。ローカルに`@napi-rs/canvas`が必要です。実ブラウザーやSafari実機テストとは区別します。

水は独立粒子による衝突シミュレーションです。本格的な圧力流体や、水の重さで線を動かす仕組みはありません。App Storeネイティブ版やオフライン保証は含みません。

Matter.js 0.20.0（MIT）を同梱。第三者ゲームの画像・音声・ステージデータは使用していません。研究と会議の判断は`docs/cyberpunk-design.md`を参照。

## 3ステージごとに切り替わる世界

全50面を17エリアに分割。1〜3面は従来のネオン街を維持し、4面以降は凍結炉心・軌道ステーション・発光温室など、専用背景とエリアカラーに切り替わります。最終エリアは49〜50面。世界マップから全エリアへ移動でき、進行記録は従来と共通です。各エリアの足場に氷・反発板・搬送ベルトなどの物理特性を設定し、線と水の両方に重力倍率を適用しています。素材の働きを利用する専用配置も含みます。

表示設定は `dist/worlds.js` にまとめています。`scripts/create-levels.cjs` による再生成で世界設定が失われることはありません。

## 足場の特性

`platform.material` は `ice`（低摩擦）、`rubber`（衝突時の反発）、`conveyor`（上面接触時の搬送）を指定できます。`beltSpeed` はpx/秒、負数で逆向き。`level.gravityScale` は線と水に共通です。素材の表面模様・ベルトの矢印と実際の作用を一致させています。

`tests/materials.cjs` は線と水への作用、非接触時のベルト無効、設計復元、長時間の反発床の安定性を検証します。
